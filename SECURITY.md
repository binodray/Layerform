# Security policy

## Supported versions

Until the first stable Windows release, security fixes are made on the latest `main` branch. Preview builds and older snapshots may not receive backports.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability that could expose user files, execute untrusted code, bypass path validation or compromise downloaded background-removal models.

Use GitHub's private vulnerability reporting flow:

<https://github.com/binodray/Layerform/security/advisories/new>

Include:

- the affected commit or version;
- clear reproduction steps;
- the expected security boundary and observed behavior;
- impact and any known workaround;
- a proof of concept only when it can be shared safely.

You should receive an acknowledgement within seven days. Please allow time for investigation and a coordinated fix before publishing details.
